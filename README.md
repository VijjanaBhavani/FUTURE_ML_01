# Sales and Demand Forecasting for Businesses

## Project Overview

This project focuses on forecasting future sales using historical business data. The objective is to analyze past sales patterns and build a Machine Learning model that can predict future sales trends.

## Dataset

The dataset contains historical sales records including:

- Order Date
- Sales
- Quantity
- Discount
- Profit

Time-based features such as Year, Month, and Day were extracted from the Order Date column for forecasting.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Methodology

1. Loaded and explored the sales dataset.
2. Converted Order Date into datetime format.
3. Created time-based features (Year, Month, Day).
4. Analyzed monthly sales trends.
5. Built a Random Forest Regression model.
6. Predicted future sales using historical patterns.
7. Evaluated model performance using MAE and R² Score.
8. Visualized Actual vs Predicted Sales.

## Model Performance

- Algorithm: Random Forest Regressor
- MAE: 108
- R² Score: 0.65

## what the Forecast Means

The forecast estimates future sales based on historical sales patterns and business-related features. It helps identify expected sales behavior and provides insights into future demand.

How Businesses Can Use This Forecast

## Businesses can use the forecast to:

- Plan inventory and stock levels
- Improve budgeting and cash flow management
- Prepare staffing requirements
- Identify periods of high and low demand
- Reduce losses due to overstocking or stock shortages

##Conclusion

The Random Forest model successfully learned sales patterns from historical data and generated useful sales forecasts. These predictions can support business decision-making and planning activities.
